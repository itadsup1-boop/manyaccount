# News Video Studio 0.4 — Tool Media only

Đính kèm file bài báo vào ChatGPT và gửi:

```text
@News Video Studio
Đọc file đính kèm và chỉ trả Tool Media Article JSON v1.
```

Tải JSON về Tool Media. ChatGPT chỉ tạo nội dung; TTS, tải stock đã có license,
phụ đề, nhạc nền và render video đều do Tool Media thực hiện. Không dùng
HyperFrames trong luồng này.
